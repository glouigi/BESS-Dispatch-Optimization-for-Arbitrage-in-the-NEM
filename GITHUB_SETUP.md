# 📤 GitHub Setup Guide

Complete guide to push BESS Optimized Dispatch to GitHub using VSCode.

---

## Step 1 — Create the Repository on GitHub

1. Go to https://github.com → sign in → click **+** → **New repository**
2. Fill in:
   - **Name**: `bess-optimized-dispatch`
   - **Description**: `⚡ NEM electricity price forecasting + BESS optimal dispatch — XGBoost ensemble + LP/MILP — Australian NEM SA1/VIC1/NSW1/QLD1/TAS1`
   - **Visibility**: Private (company) or Public
   - ❌ Do NOT tick "Add README", "Add .gitignore", or "Choose a licence" — you have all these already
3. Click **Create repository** — keep the browser tab open

---

## Step 2 — Open Project in VSCode

**File → Open Folder** → select the folder containing `BESS_Optimized_Dispatch.ipynb`

---

## Step 3 — Configure Git (one-time)

Open terminal: `Ctrl + `` ` ``

```bash
git config --global user.name  "Your Name"
git config --global user.email "you@yourcompany.com"
```

---

## Step 4 — Initialise and First Commit

```bash
git init
git add .
git status          # verify before committing
```

**Expected files staged — only these:**
```
BESS_Optimized_Dispatch.ipynb
app.py
bess_pipeline.py
README.md
requirements.txt
environment.yml
.gitignore
LICENSE
GITHUB_SETUP.md
STREAMLIT_DEPLOY.md
.github/workflows/ci.yml
```

**Should NOT be staged (excluded by .gitignore):**
```
data/*.parquet          ← large files, cached locally
models/*.pkl            ← large files, regenerated by running notebook
outputs/*.png           ← regenerated on every run
outputs/*.csv           ← regenerated on every run
```

If large files got staged accidentally:
```bash
git rm --cached "data/*.parquet"
git rm --cached "models/*.pkl"
git rm --cached "outputs/*.png"
git rm --cached "outputs/*.csv"
```

Now commit:
```bash
git commit -m "feat: BESS Optimized Dispatch — NEM ML pipeline + Streamlit app"
```

---

## Step 5 — Connect and Push

```bash
# Replace YOUR_USERNAME with your actual GitHub username:
git remote add origin https://github.com/YOUR_USERNAME/bess-optimized-dispatch.git
git branch -M main
git push -u origin main
```

VSCode will open a browser to authenticate with GitHub — follow the prompts.

**Successful output:**
```
Enumerating objects: 14, done.
Writing objects: 100% (14/14), 145.00 KiB | 3.50 MiB/s, done.
To https://github.com/YOUR_USERNAME/bess-optimized-dispatch.git
 * [new branch]      main -> main
```

## Common Issues

**"remote origin already exists"**
```bash
git remote set-url origin https://github.com/YOUR_USERNAME/bess-optimized-dispatch.git
```

**"Authentication failed"**
```bash
# Install GitHub CLI: https://cli.github.com
gh auth login
# Follow browser prompts
```

**Notebook shows as binary / no diff preview**

This is normal for `.ipynb` files. Install nbstripout to clean outputs before commit:
```bash
pip install nbstripout
nbstripout --install   # strips outputs on every commit automatically
```

**Large file error (>100 MB)**
```bash
# Find large files:
git ls-files | xargs du -sh | sort -rh | head -10

# Remove from tracking:
git rm --cached path/to/large/file
echo "path/to/large/file" >> .gitignore
git commit -m "chore: remove large file"
git push
```
